# Board Deck Outline

Use this outline when the request is executive-facing, decision-oriented, or board-ready.

## Audience
- Board / executive audience:
- Decision owner:
- Time available:

## Core Decision
- What single decision or conclusion should this deck support?

## Narrative Arc
1. Context
2. Key finding
3. Options / trade-offs
4. Recommendation
5. Next steps

## Slide Plan

### 1. Hero
- conclusion-first title
- subtitle / context line
- background visual direction

### 2. Executive Summary
- 3 to 5 bullets only
- decision, impact, timing, risk

### 3. Section Divider
- short transition statement

### 4. One-column / Argument Slide
- one message
- 3 to 5 supporting bullets

### 5. Two-column Comparison
- option A vs option B
- or current state vs target state

### 6. Two-column With Image
- proof visual on one side
- interpretation on the other side

### 7. Next Steps / Decision Required
- owner
- action
- timing
- open risks
